# iRefurb Chennai — Mobile Screen & Genuine Parts Repair Website

A sleek, responsive, single-page dark-mode website built for **iRefurb Chennai** (Mount Road, Chintadripet). Designed with zero external dependencies, custom SVG branding, and instant WhatsApp quote integration for smartphone repairs.

## ✨ Key Features

- **Custom Brand Identity:** Custom inline SVG logo featuring smartphone & precision repair tool artwork, paired with a dark-navy (`#080c14`) and electric sky-blue (`#0095ff`) UI.
- **Interactive WhatsApp Quick Quote Request:** Dynamic brand-to-model dropdown selector (Apple, Samsung, OnePlus, Google Pixel, Xiaomi, Vivo, Oppo, Realme) with live character counting and pre-filled WhatsApp message generation.
- **Live IST Store Status Badge:** Automatically calculates Indian Standard Time (IST) against store hours (Mon–Sat, 10:30 AM – 10:30 PM) to display real-time **Open now** / **Closed now** indicators.
- **The iRefurb Promise:** Highlights core service guarantees—*Original Displays & Original Parts*, *Genuine Spares Only*, *Fast Fix. Flawless Finish.*, and *Express Same-Day Service*.
- **Customer Reviews & Store Location:** Showcases the 4.9/5.0 Google rating, direct click-to-call CTA (`+91 81223 34434`), and Google Maps directions to SSR Mall, Wallers Road, Mount Road, Chennai.
- **Fully Responsive & Self-Contained:** Adapts seamlessly across mobile, tablet, and desktop viewports with zero external CSS or JS framework dependencies.

## 🛠️ Tech Stack

- **Frontend:** Semantic HTML5, Modern CSS3 (CSS Grid, Flexbox, Custom Properties), Vanilla JavaScript (ES6+)
- **Graphics:** Inline Scalable Vector Graphics (SVG)
